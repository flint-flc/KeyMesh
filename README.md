# KeyMesh

A Post-Quantum Cryptography Migration and Verification Platform.

## About

KeyMesh helps developers evaluate and migrate applications
from classical cryptographic key establishment to supported
hybrid post-quantum mechanisms.

## Planned Features

- Classical X25519 key establishment
- ML-KEM integration
- Hybrid TLS 1.3 verification
- Cryptographic benchmarking
- Migration analysis and guidance
- Web-based dashboard

## Tech Stack

- C++20
- OpenSSL 3.5+
- CMake
- React (planned)
- PostgreSQL (planned)
- Docker (planned)
